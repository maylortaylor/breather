# Breather

A calm, installable web app for winding down. Layered synthesized sound, an optional soft metronome, a guided 4-7-8 breath and a slow aurora background that breathes with you.

Every sound is generated live with the Web Audio API, so v1 ships no audio files. Everything is optional: music, effects, metronome and breathing text can each be turned fully off. It works offline and installs like an app (PWA).

**Status:** pre-v1, local only. No remote, no releases.

The build plan is [`docs/PLAN.md`](docs/PLAN.md). How work is done here is [`docs/WORKING-AGREEMENT.md`](docs/WORKING-AGREEMENT.md).
